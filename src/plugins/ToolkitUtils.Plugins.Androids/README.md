# Androids

This plugin is responsible for augmenting ToolkitUtils with support for
"Androids," a mod for RimWorld that adds a new type of pawn called "Androids."
At the moment, this plugin only extends ToolkitUtils' "surgery" event to ensure
viewers can install android parts into their metallic pawn, as well as ensure
viewers cannot install android parts into "fleshy" pawns.
