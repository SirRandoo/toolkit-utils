# A RimWorld of Magic

This plugin is responsible for augmenting ToolkitUtils with support for
"A RimWorld of Magic," a mod for RimWorld that adds a lot of content to
RimWorld. This plugin currently augments the "trait" events to ensure they
properly handle the trait "classes" added by A RimWorld of Magic. These classes
contain internal data that must be cleared after the class is changed or removed
from a pawn. This plugin also adds two new commands: one that allows viewers to
see an overview of their pawn's class(es), and another that allows viewers to
spend skill points their pawn has acquired.
