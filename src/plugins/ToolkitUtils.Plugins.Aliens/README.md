# Humanoid Alien Races

This plugin is responsible for augmenting ToolkitUtils with support for
"Humanoid Alien Races," a mod for RimWorld that provides a framework for mod
developers to create custom races. At the moment, this plugin only extends
ToolkitUtils' "pawn" event to ensure viewers can properly purchase pawns,
including pawns that use the Humanoid Alien Races framework.
