# ToolkitUtils

## Features

ToolkitUtils provides a wide range of features to improve mod functionality and customization:

- A **collection of events** to extend gameplay possibilities.
  [Learn more](https://sirrandoo.github.io/toolkit-utils/events.html)
- A **collection of commands** to personalize commands for viewers.
  [Learn more](https://sirrandoo.github.io/toolkit-utils/commands.html)
- A **collection of tweaks** to adjust various game mechanics.
  [Learn more](https://sirrandoo.github.io/toolkit-utils/tweaks/)
- The ability to **individually set trait prices**, adding more granularity to your gameplay.
- A tool to **clean up old viewers** from your saved viewers file to maintain efficiency.
- Additional **mod compatibility** for seamless integration.
  [Learn more](https://sirrandoo.github.io/toolkit-utils/modcompat.html)

## Installation

## Manual Installation

1. Download the latest release of ToolkitUtils from
   the [release page](https://github.com/UserName/ToolkitUtils/releases).
2. Extract the files from the archive.
3. Place the extracted folder in your game's `Mods` directory.
4. Ensure TwitchToolkit is installed and active.
5. Launch your game, and ToolkitUtils should be ready to use!

## Steam Workshop

1. Subscribe to ToolkitUtils on the Steam Workshop.
2. Launch your game, and the mod will automatically download and install.
3. Ensure TwitchToolkit is installed and active.
4. ToolkitUtils should be ready to use!
